## Typography
- Font: Be Vietnam Pro (google_fonts)
- Body ≥ 14sp; titles 18–22sp bold
- Touch targets ≥ 48dp; primary buttons min height 52dp

## Spacing
- Page padding 16–24
- Card radius 16
- Button radius 12
- Section gap 12–24
